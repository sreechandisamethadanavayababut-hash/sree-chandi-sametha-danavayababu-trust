# 🛕 Sree Chandi Sametha Danavayababu Trust

Official website for temple construction, events, and donations.

---

## 🌟 About the Project

This website is created for the **Sree Chandi Sametha Danavayababu Trust** to support the construction of the temple and to provide information to devotees.

The platform allows users to:

* View temple details
* Explore events and rituals
* Donate for temple construction
* Contact the trust easily

---

## 🙏 Features

* 🏠 Home page with temple details
* 📖 About page with events and rituals
* 📸 Image gallery
* 💰 Donation section (UPI & QR)
* 👥 Donators list
* 📞 Contact page (Call, Email, Maps integration)
* 🌙 Dark / Light mode

---

## 💰 Donation

Devotees can support the temple construction through:

* UPI Payment
* QR Code Scan
* WhatsApp Confirmation

Every contribution helps in building this sacred temple 🙏
